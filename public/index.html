Tạo chiến dịch mới

Chiến dịch đã khởi chạy (Locked): Các thông số cốt lõi (URL, Target, Chế độ phân bổ, Engine, Proxy, Thời gian) đã bị khóa an toàn để tránh xung đột lịch trình. Nhấn Reset ngoài danh sách nếu bạn muốn cấu hình lại từ đầu.
Browser QA: Render DOM/JS thật bằng Browserless.io Chromium. HTTP: Subrequest Cloudflare fetch() tốc độ cao.
Định nghĩa chuỗi hành động Puppeteer tuần tự (mở trang, chờ selector, click, nhập liệu, assert chữ). Tự động lưu ảnh chụp nếu bước bị lỗi.
Proxy Clock
Lưu ý Browserless Cloud Free: External proxy bên thứ ba yêu cầu gói Paid của Browserless.io (gói Free sẽ nhận HTTP 401 Unauthorized khi chạy Chromium). Nếu bạn dùng gói Free, vui lòng chuyển Engine sang ⚡ HTTP Subrequest hoặc bỏ chọn proxy.
Hỗ trợ HTTP/HTTPS/SOCKS5 proxy hoặc Gateway URL (ví dụ: http://user:pass@ip:port hoặc gateway forwarder).
Proxy Clock độc lập: Tính theo thời gian tuyệt đối slot = floor((now - base) / interval) % pool.length. Các lượt click trong cùng cửa sổ 2 phút sẽ dùng chung proxy mà không cần đổi mỗi lượt.
SMART: Ít lúc sáng sớm → Tăng dần → Cao điểm trưa & chiều → Tự động tính toán lại nhịp nếu server bị lag.
